This file has basic instructions to run each loss function we made.

Note: Use WnB or html file to visualise the training
to run html file command is 
xdg-open checkpoints/E1/web/index.html

Baseline model(E1) - Training
python train.py \
  --dataroot ./datasets/art_dataset \
  --name E1 \
  --model cycle_gan \
  --batch_size 1 --load_size 256 --crop_size 192 \
  --n_epochs 50 --n_epochs_decay 50 \
  --save_epoch_freq 10

Baseline model(E1) - Testing
python test.py \
  --dataroot ./datasets/art_dataset \
  --name E1 \
  --model cycle_gan \
  --phase test --epoch latest \
  --num_test 100
